# GitHub Pages 公開手順

このデータは、福島商店・NABEXの全11ページをGitHub Pagesへ自動公開できるように設定済みです。

## 公開方法

1. GitHubで新しいリポジトリを作成します。
2. ZIPを展開し、中にあるファイルとフォルダをすべてリポジトリへアップロードします。
3. GitHubのリポジトリで `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `GitHub Actions` にします。
5. `main` ブランチへアップロードすると、自動でサイトが生成・公開されます。

公開処理はリポジトリの `Actions` タブで確認できます。完了後、`Settings` → `Pages` に公開URLが表示されます。

## 更新方法

サイトのファイルを変更して `main` ブランチへアップロードすると、自動で再公開されます。リポジトリ名を変更しても、画像とページリンクは自動的に新しいURLへ合わせて生成されます。

## お問い合わせについて

電話番号・メールアドレスのリンクはそのまま利用できます。NABEXのお問い合わせフォームは現在デザイン見本のため、送信機能を利用する場合は別途フォームサービスとの接続が必要です。
